## 3. Motion References & Operational Timing Catalog

Located in [`phase2-research/motion/`](file:///run/media/tarun/Tarun%20Files1/AegisOps/AegisOps%20Design/phase2-research/motion/):

### 3.1 Observed & Documented Reference Behaviors
1. **Sidebar Collapse / Expand**:
   - Vercel's February 2026 sidebar animates width smoothly via CSS `transition: width 200ms cubic-bezier(0.4, 0, 0.2, 1)`.
   - Content inside sidebar fades out labels (`opacity: 0`) while keeping icons centered in compact rail mode (`width: 56px` vs `width: 240px`).
2. **Context Menu & Dropdown Transitions**:
   - Menus open instantly with a subtle scale and opacity entrance (`opacity: 0 -> 1`, `scale: 0.98 -> 1`, duration `100ms`, `ease-out`).
   - Zero spring or bounce overshoot (strict enterprise restraint).
3. **Card Hover Response**:
   - Border color transitions from subtle rule (`#b3b3af` or `var(--accents-2)`) to high-contrast ink (`#282828` or `#ffffff`) over `150ms`.
   - Elevation lift: Optional 1px translateY or subtle shadow shift (`0 4px 12px rgba(0,0,0,0.08)`).
4. **View Mode Switching (Grid <-> List)**:
   - Instant DOM reflow without cross-fading card items to prevent visual layout stutter or slow rendering on large lists.
